

# Number Guessing Game 🎮

A beginner-friendly console-based game developed using C.

## Features

- 3 difficulty levels
- Limited attempts
- Score calculation
- Best score tracking
- Play again option
- Random number generation

## Concepts Used

- Variables
- if-else
- Loops
- Functions
- Random number generation
- User input

## How to Run

Compile and run the C program using any C compiler.
